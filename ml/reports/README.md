# Generated evaluation reports

**Everything in this directory is generated, never hand-written.**

Once the evaluation suite (P3-15) exists, CI regenerates these and fails the build
on any diff. That is deliberate: benchmark numbers drifting away from the code that
produced them is the specific defect that sank the previous iteration of this
project, where a demo script quoted five figures that had never been generated and
this directory was empty on the day of review.

Expected contents:

- `baseline_metrics.md` — deterministic Otsu baseline on the held-out split
- `model_metrics.md` — learned model, reported *beside* the baseline, never alone
- `calibration_<date>.md` — ECE and reliability diagram, fitted on validation only
- `ablation.md` — comparison rows, including any foundation-model experiment

Rule: no number appears in a slide, a README or a demo script unless it exists in a
committed file here, generated by a committed script.
