5. Engineering Rules

 All internal APIs use /api/v1; breaking changes require versioning and P1 review.

 Canonical ErrorResponse: code, message, details[], retryable, trace_id.

 Propagate trace_id, mission_id, run_id, job_id, organization_id where applicable.

 organization_id comes from verified auth context, never a request body.

 No cross-service private DB reads.

 Long-running EO/ML/report/monitoring work returns 202 + job_id.

 Results retain dataset_id/observation_ids/model_version/processing_version as applicable.

 Idempotency-Key is used for duplicate-sensitive writes.
