## Engineer: Swarali
**Role:** Frontend UX Engineer

## 1. Executive Summary
Your responsibility is to make the immense complexity of the Autonomous Earth Investigator visually intuitive, premium, and stunning. You must build dynamic, highly interactive UI components that explain the AI's reasoning, handle temporal timelines, and wow the judges.

## 2. End-to-End Implementation Guide

### A. Earth Time Machine UI
Users need to visualize change over time.
- **Action:** Build a dynamic timeline slider (Jan → Feb → Mar). When the user drags the slider, smoothly transition the MapLibre layers (via TiTiler) to show historical satellite imagery and semantic change maps.

### B. Evidence Graph / WHY Panel
This is the signature feature for explainability. 
- **Action:** When a user clicks an insight in the chat or map (e.g., "14 buildings affected"), slide out an `EvidencePanel`. Use a node-graph visualization library (like React Flow) to show exactly how the AI arrived at this conclusion: `Insight -> Confidence Gate (0.91) -> SAR Model -> T1/T2 Assets`.

### C. Multi-Sensor Disagreement & Agentic UI
The UI must feel like it's communicating with an active investigator, not a static dashboard.
- **Action:** Listen to the WebSocket for `SENSOR_DISAGREEMENT` and `ACQUIRING_EVIDENCE` events. Display beautiful, non-intrusive toast notifications or chat bubbles: *"⚠ Optical and SAR sensors disagree on flood extent. Acquiring additional radar observation..."*

### D. Infrastructure Impact Graph
- **Action:** Build a dashboard or side-panel that visualizes the PostGIS data Kavin generates. Show a hierarchical breakdown of affected infrastructure (Flood -> Roads -> Hospitals).
