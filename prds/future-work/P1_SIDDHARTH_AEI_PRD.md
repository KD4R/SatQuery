## Engineer: Siddharth
**Role:** Backend & Gateway Engineer

## 1. Executive Summary
Your responsibility in the "Autonomous Earth Investigator" project is to build the API boundaries, real-time state propagation, and persistence layers that allow the frontend to orchestrate the complex agentic reasoning loops happening in the AI/ML layers. You are the glue between Swarali’s UI and Kedar’s LangGraph agents.

## 2. End-to-End Implementation Guide

### A. Real-Time Event Streaming (WebSocket Expansion)
The current WebSocket implementation streams basic mission progress. You must expand this to handle highly complex, asynchronous events generated by the LangGraph agent:
- **Event: `SENSOR_DISAGREEMENT`:** The agent found conflicting data. You must push this to the frontend so Swarali can render the warning panel.
- **Event: `ACQUIRING_EVIDENCE`:** The self-improving loop triggered. Push an update that the agent is actively pausing to fetch new STAC assets.
- **Event: `IMPACT_GRAPH_UPDATED`:** Push real-time PostGIS intersection results.
**Action:** Update `services/gateway/routers/missions_ws.py` to listen for these new event types on the Redis/Celery pub-sub streams and proxy them to the P5 frontend.

### B. Mission Memory & Persistence
The agent must remember past missions. "Monitor this corridor" requires state. 
**Action:** 
- Design a `MissionMemory` schema in the database (PostgreSQL/MongoDB).
- Create endpoints `GET /api/v1/missions/{id}/memory` and `POST /api/v1/missions/{id}/memory`.
- This allows Kedar's agent to fetch the historical context of an AOI before making new decisions.

### C. Earth Time Machine API
Swarali needs a timeline UI. She needs to query historical data.
**Action:** 
- Create an endpoint `GET /api/v1/locations/{aoi}/history?start_date=X&end_date=Y`.
- This route will proxy to Kavin's Geodata service to return a list of available COGs and temporal analysis graphs.

### D. Secure & Production-Ready
All endpoints must be locked down. Tenant isolation is mandatory. An attacker should not be able to trigger expensive ML inferences or STAC catalog searches by bypassing the JWT gateway.
